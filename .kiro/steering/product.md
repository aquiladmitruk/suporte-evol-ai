# Product

**Evol ERP AI Assistant** is a RAG-based chat assistant that helps users get support for the Evol ERP system. Users ask questions in natural language and the assistant retrieves relevant content from ingested documents (PDFs) stored in a Qdrant vector database, then generates answers via an LLM.

## Core Capabilities
- Conversational chat with session-based history
- Semantic document retrieval (RAG pipeline)
- PDF document ingestion and chunking
- Source attribution — responses include references to the source documents and pages

## Language
The codebase, comments, docstrings, and user-facing strings are written in **Brazilian Portuguese**. Keep this convention when adding new code or documentation.
